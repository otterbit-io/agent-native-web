Important - static vs. runtime: Live agent detection cannot be performed based on files alone. That's why the tool generates a /agent/-mirror and server-configs that redirect known agent user-agents to it on your sever. The mirror displays the same content as the original page, but in a machine-readable format - the canonical tag points to the original URL. Any differing content would constitute deceptive cloaking. Additionally, user-agent detection can be spoofed and is never complete.
